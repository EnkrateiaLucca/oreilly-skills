# Week 2: A second brain my agents can read

O'Reilly Skills Live, Nov 17, 2026. How I keep my notes, rules and skills in one Obsidian vault that Claude Code, Codex and scheduled tasks all read from and write back to.

**This week's material has its own repo:** [louisfb01/obsidian-agent-vault-template](https://github.com/louisfb01/obsidian-agent-vault-template)

```bash
git clone https://github.com/louisfb01/obsidian-agent-vault-template.git
```

It's a ready-to-use Obsidian vault for running an AI agent as a personal OS, with:

- one rules file every agent reads first;
- a hub note per area so agents find things;
- example skills with feedback logs;
- templates for projects, progress logs and scheduled runs.

Open the folder as a vault, then follow its `START-HERE.md`. To bring your own notes in, ask Claude or Codex to move them in following the vault's rules.
