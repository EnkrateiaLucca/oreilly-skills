Five rules for a good artifact

One fileno build step, a few pinned CDN libs
One joba page per decision, not an app
Options side by sidefan out three, point at one
Inputs over prosesliders, drag, toggles, text boxes
End with exporta Copy button back to the agent

keep it a few hundred lines, so any model can rewrite it

rule 5, up close

End with export

Copy 
{ "keep":   ["post-1", "post-3"],
  "reject": ["post-2"],
  "why": {
    "post-2": "the hook buries the number"
  } }

export the why, not just the picks

Paste it into Claude Code.
The next agent gets a brief, not a list.

Three sentences for your next prompt

“Make it one HTML file. No React, no build step.”
“Show me 3 options side by side so I can point at one.”
“End with a Copy button that hands my choices back to you.”
